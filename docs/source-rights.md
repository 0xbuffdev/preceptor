# Source and release status

Preceptor's engineering foundation is in this standalone repository. The current bootstrap is original scaffolding; no private application implementation, learner content or provider code was transferred. The development dependency lock resolutions match the sibling Assay toolchain; no Assay runtime source is included.

On 2026-11-28 the maintainer selected Apache-2.0, matching Assay. See [LICENSE](../LICENSE) and [COPYRIGHT.md](../COPYRIGHT.md). The package remains private and unpublished at version `0.0.0`. Contributor rights, provenance review, source visibility and publication remain separate gates. No publication configuration is established by this foundation.

The intended first release remains subject to the canonical specification, source review and approval. No registry publish, release tag or host deployment is authorized by engineering checks.
